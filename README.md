# 走你 · 计划赶得上变化

**点几下就出一份能直接走的旅行攻略，路上有变自己重排。**

🔗 **[打开使用 →](https://ourword.ai/zouni/)**

---

## 这是什么

大部分旅行攻略给你的是一堆信息，你还得自己排。走你给你的是一份**排好的行程**：选目的地、选几天、选预算、选想玩什么，几秒钟出结果——每天几点出发、几点到哪、住哪儿、花多少，全都算好。

真正的区别在**路上**：下雨了、景区管制了、想临时加一站，点一下，后面的时刻表自动重排，费用跟着变。计划赶得上变化，所以计划本身要会变。

## 现在有什么

- **21 条可用行程 · 15 个目的地** — 北疆环线、青甘大环线、川西、稻城亚丁、西藏、滇西北、梅里雨崩、额济纳、呼伦贝尔、桂林、张家界、黄山、香港、都江堰、日本关西
- **多种天数可选** — 同一条线 8/10/12/15 天，行程自动重排不是简单裁剪
- **算得清的钱** — 门票、餐饮、交通、住宿分项到人；自驾按实时里程估油费，公交按每人实付
- **中英双语 · 五种货币** — 按浏览器语言和时区自动切换，也可手动
- **路上会变** — 天气管制一键重排；顺路的备选点可以当场加进当天
- **存在你自己手机里** — 无账号、无服务器、不上传；可导出备份、可把整份行程压进链接发给朋友
- **能装到桌面** — PWA，添加到主屏后像个 App，离线也能打开

## 技术

单文件 HTML，零依赖零构建，直接双击就能跑。兼容微信内置浏览器的老内核。

发布前过九道自动化关卡：语法检查 → 21 条线路引擎仿真 → 静态终检 → 双版本运行时冒烟 → 视觉回归（真渲染截图断言）→ E2E 真浏览器点击链 → 数据体检 → 可访问性（WCAG AA）。

```bash
bash zouni-tests/run-all.sh
```
